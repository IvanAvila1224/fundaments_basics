# Java Fundamentals - POO Básico

Repositorio de ejercicios prácticos para aprender los fundamentos de Java y Programación Orientada a Objetos (POO) desde cero.

## Temas cubiertos

- **Clases y Objetos** — creación de clases, atributos y métodos
- **Encapsulamiento** — modificadores de acceso, getters y setters
- **Herencia** — reutilización de código con `extends`
- **Polimorfismo** — mismo método, comportamiento diferente según el objeto
- **Abstracción** — clases abstractas e interfaces
- **Manejo de Excepciones** — `try/catch/finally` y excepciones personalizadas
- **Colecciones** — `ArrayList` y `HashMap`
- **Generics** — clases reutilizables con tipo genérico `<T>`
- **Streams y Lambdas** — filtrado y transformación de datos de forma moderna

## Tecnologías

- Java 17+
- Maven
- Spring Boot (estructura base)
